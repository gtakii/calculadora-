# calculadora-

Calculadora web desenvolvida com HTML, CSS e JavaScript, com operações matemáticas, histórico de cálculos e temas claro e escuro.

## Funcionalidades

- Operações de adição, subtração, multiplicação e divisão.
- Interface responsiva.
- Temas claro e escuro.
- Histórico dos últimos 15 cálculos.
- Armazenamento do histórico no navegador.
- Preferência de tema salva.
- Suporte ao teclado.
- Exclusão individual de cálculos.
- Limpeza do histórico.
- Formatação de números no padrão brasileiro.
- Tratamento de divisão por zero.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts (Inter)

## Demonstração

**[Acessar Calculadora Web](https://gtakii.github.io/calculadora-/)**

## Executar localmente

Clone o repositório:

```bash
git clone https://github.com/gtakii/calculadora-.git
```

Entre na pasta:

```bash
cd calculadora-
```

Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor.

## ⌨️ Atalhos do teclado

| Tecla | Ação |
|---|---|
| 0–9 | Inserir números |
| + - * / | Operações |
| Enter ou = | Calcular |
| Backspace | Apagar último dígito |
| Esc ou C | Limpar |
| . ou , | Separador decimal |
